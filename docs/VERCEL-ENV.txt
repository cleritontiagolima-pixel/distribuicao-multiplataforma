# ============================================================
# CTUBE — Variáveis de ambiente para a VERCEL (produção)
# ============================================================
# COMO USAR:
#   1. Baixe este arquivo no seu computador.
#   2. Preencha os valores marcados com TROQUE (veja instruções abaixo).
#   3. Renomeie para "producao.env" (qualquer nome serve — a Vercel não
#      importa arquivos .env diretamente; as variáveis são coladas uma a uma).
#   4. Na Vercel: abra o projeto → Settings → Environment Variables.
#   5. Para CADA variável abaixo, clique "Add New", cole o NOME e o VALOR,
#      marque o ambiente "Production" e salve.
#   6. Deployments → "..." do último deploy → "Redeploy" para aplicar.
#
# ------------------------------------------------------------
# IMPORTANTE:
# - CTUBE_PLAN=paid BLOQUEIA os downloads para quem não tem licença anual.
#   Use "free" (ou remova a variável) para liberar downloads para todos.
# - GERE segredos aleatórios com 64+ caracteres. No seu PC rode:
#     node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
#   Rode 2 vezes (uma para LICENSE_SECRET, outra para ADMIN_SECRET).
#   NÃO use o mesmo valor nos dois.
# - Depois de trocar qualquer variável, faça um novo Deploy.
# ------------------------------------------------------------
